# 图片工具 · Image Tools

一个扩展包，两个独立动作，每个动作有自己的本地 HTML 弹窗。需要支持 schema 2 的 MenuMate。

| 动作 | 输入 | 选项 |
| --- | --- | --- |
| 图片压缩 | JPEG | 质量、最长边、输出目录 |
| 图片格式转换 | PNG、JPEG、TIFF、GIF、HEIC | PNG/JPEG/TIFF 格式、JPEG 质量、输出目录 |

两种操作均保留原图，重名自动编号。转换为 JPEG 不保留透明背景；动图、多页图片只导出单帧／单页。
页面支持中文和英文，跟随 MenuMate 传入的语言。动作名称是清单中的作者文案。

## 本地试用

运行主项目的 `scripts/prepare-image-tools-pack.sh`，它会输出一个独立的本地 Git 仓库路径。
在 MenuMate 的「扩展包 → 导入」粘贴该路径，查看两个动作的脚本和 HTML 后确认导入。
两个动作默认关闭，可分别试运行、启用；更新和卸载按整个扩展包处理。
试运行会自动生成临时图片，点击开始后打开该动作的 HTML 弹窗。

这个包无需下载运行依赖，调用 macOS 自带的 zsh、sips 和 plutil。
发布时将本目录内容作为独立仓库的根目录；主项目的 GitHub 地址不能直接导入本子目录。
